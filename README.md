# PT Perkasa Nusantara Sejahtera

A modern static corporate landing page for PT Perkasa Nusantara Sejahtera, a company focused on purchasing LCD and LED TV panels in bulk quantities for industrial and commercial needs.

## About the Project

This project is a company website created to support business outreach and streamline the process of receiving panel purchase offers from partners. The landing page is designed to help the company present its business profile, explain purchasing requirements, and convert visitors into leads through WhatsApp and inquiry forms.

## Business Scope

PT Perkasa Nusantara Sejahtera specializes in buying LCD/LED TV and monitor panels in large volumes, especially for conditions that meet company quality standards. The website is designed to support the following business goals:

- Receive bulk panel purchase offers from suppliers
- Show product listings and stock information
- Explain terms and conditions clearly
- Simplify customer communication via WhatsApp
- Collect inquiry data through a structured contact form

## Features

- Responsive landing page for desktop and mobile
- Hero section with strong call-to-action
- Company profile and service center information
- Product filter by panel size and condition
- Product card layout with image, specs, and stock details
- Detail modal for product information
- WhatsApp floating contact button
- Offer submission form for suppliers and business partners
- SEO meta tags for search engine visibility
- Lightweight static implementation without frontend framework

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome
- AOS (Animate On Scroll)
- Netlify Forms

## Getting Started

This is a static website, so no build tools or package installation are required.

### Option 1: Open directly in the browser

Open `index.html` directly in your browser.

### Option 2: Run a local web server

From the project root, run:

```bash
python -m http.server 8000
```

Then open:

```text
http://localhost:8000
```

## Business Requirements Highlight

The website clearly communicates the key purchase requirements:

- Minimum transaction: 500 units per invoice
- Panel must be in working condition / 100% active
- Panel must be single socket type
- Payment is made after location inspection and verification
